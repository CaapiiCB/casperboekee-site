# casperboekee.com

Website van Casper Boekee Personal Training (Muay Thai & Functional Strength, Amsterdam).

- De live site staat in de hoofdmap en wordt gehost met GitHub Pages.
- De bron (teksten, prijzen, sjablonen) staat in `bron/`. Teksten en prijzen pas je aan in `bron/content.py`.
- Opnieuw bouwen: zet `bron/static/img/` aan met de afbeeldingen uit `assets/img/`, draai `python3 build.py` in `bron/` en kopieer `bron/out/dist/` naar de hoofdmap.
